# Kahlua｜BIGLOBE光 DB不備チェック Part2（試作 v0.1.0）

対象マニュアル：`【BIGLOBE光】DBマニュアル_261029.xlsx` の `【個人】DB不備チェック`、`【法人】DB不備チェック`（2026/10/29版）。

## インストール（GitHub配布）

1. Chrome / Edge で Tampermonkey を有効にします。
2. **[Part2 スクリプトをインストール](https://raw.githubusercontent.com/fttmgotanda-blip/ft-salesforce-audit/main/kahlua-biglobe-audit/kahlua-biglobe-audit.user.js)**を開きます。
3. Tampermonkey のインストール確認画面で内容を確認してインストールしてください。
4. Kahlua の申込情報（個人／法人）の詳細表示画面を再読み込みします。
5. 右上のパネルで「不備チェック実行」を押します。必要に応じて「タブ巡回・再チェック」を押します。

自動インストール画面が出ない場合は、Tampermonkey の「ユーティリティ」から上記 URL をインポートしてください。

## 更新方法

このスクリプトには `@updateURL` と `@downloadURL` を設定済みです。管理者が main のスクリプトの `@version` を上げて更新すると、Tampermonkey の更新確認時に最新版を取得できます（即時ではありません）。

- 前回の Salesforce 用スクリプトとは **別スクリプト**として動作します。
- Kahlua の対象詳細画面でのみ処理します。
- データを保存・編集・自動差戻しする機能はありません。

## 実装済みの主要項目

- 個人・法人の画面判別
- 説明書面進捗とユーザ備考、発送日の整合
- 個人70歳以上の書面フロー判定、一本化・FC進捗／担当／完了日の整合
- 申込区分と申込プランの整合、転用・事業者変更承諾番号
- 申込者・契約者の氏名、文字数、カナ、連絡先、メール形式
- 設置先／BIGLOBE登録住所の空欄・桁数・文字数・ローマ数字
- 法人の法人名・BLUE使用有無・契約者連絡先・申込区分
- 工事希望日・工事費支払方法・管理会社情報の一部条件
- 光電話／光テレビとAC備考、番号ポータビリティ、代表的オプション組合せ
- N+同時訴求、BIGLOBEオプション件数の候補照合
- Wi-Fiルーターの速度別条件、代表的な機種の整合
- キャッシュバックの金額・理由・メール形式
- 水トス成功時の折衝進捗・操作履歴の一部照合

## 見方と注意

- **要修正候補**：マニュアルと不一致が疑われるため確認。自動差戻しはしません。
- **適合候補**：当該チェック条件では問題を検出しませんでした。他のチェックや通話内容まで保証するものではありません。
- **判定保留**：画面から確認できない、情報不足、複数タブの同名項目、又は目視が必要な条件です。
- **対象外**：その案件では条件を適用しません。
- 一覧の項目をクリックすると、該当項目へスクロール・強調表示を試みます。タブのHTML構造により開けない場合があります。
- 結果コピーは**項目名・判定・一般的な確認理由のみ**。画面の顧客氏名、電話番号、住所、メール、入力データは含みません。
- データの外部送信、Kahluaへの更新、差戻し実行は行いません。
- 10ギガルーター48パターンや通話内容・操作履歴の意味判断などは、今回の試作では判定保留を一部残しています。
- 実画面のDOM・動作で実行テスト済みの完成品ではありません。Tampermonkeyに導入した初回は、個人・法人各1件ずつ、手動チェック結果と照合して調整してください。
- 前回の Salesforce 用スクリプトとは別スクリプトです。GitHub 経由の更新確認に対応しています。
